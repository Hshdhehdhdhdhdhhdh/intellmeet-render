# IntellMeet Design Direction

## Chosen Direction

The supplied IntellMeet interface is the ground-truth visual specification. Preserve its calm, premium dark workspace aesthetic rather than introducing a competing redesign.

## Design Movement

Modern enterprise productivity software with restrained sci-fi accents and an editorial dashboard rhythm.

## Core Principles

Clarity first, compact information density, obvious interactive affordances, consistent visual hierarchy, and calm feedback. Existing content and capabilities remain visible; fixes add clarity without deleting or simplifying the product.

## Color Philosophy

Near-black navy surfaces create focus. Teal is the signature action and success color. Violet supports AI and collaboration moments. Amber and rose are reserved for status and emphasis. Native controls must participate in the dark color scheme, including dropdown menus and focus states.

## Layout Paradigm

A fixed left workspace navigation and sticky top command bar frame a responsive card-based content canvas. Dialogs stay centered and compact; meeting details remain in a right-side drawer. Mobile retains the existing collapsed-sidebar behavior.

## Signature Elements

The IntellMeet sparkle mark, subtle radial color fields, rounded low-contrast panels, teal focus rings, status dots, waveform accents, avatar stacks, and the gradient primary action button.

## Interaction Philosophy

Every control that looks interactive must perform a visible action. Hover, pressed, focus, disabled, loading, success, and error states must be perceptible. Copilot uses a familiar chat composer with clearly visible send and attachment controls. Meeting inputs use native date/time/select controls but remain readable in the dark theme.

## Animation

Keep the existing short rise-in and slide-in transitions. Motion remains subtle, quick, and disabled for reduced-motion users.

## Typography System

DM Sans for interface copy and Manrope for prominent headings and brand moments. Preserve the current compact sizing and hierarchy while maintaining readable contrast.

## Brand Essence

Focused collaboration that turns conversations into action.

## Brand Voice

Clear, capable, calm, concise, and helpful. Avoid exaggerated claims about prototype data or features that are not backed by persistent services.

## Wordmark and Logo

Keep the existing IntellMeet wordmark. The project icon uses the existing sparkle/meeting-intelligence metaphor as a simple flat mark with strong negative space and no text.

## Signature Brand Color

IntellMeet Teal: `#6CE4DF` against deep navy `#070B12`.
